# Keybinds

Generated from Hyprland's binds with `ghost keybinds > docs/keybinds.md`; every bind in
`hypr/.config/hypr/binds.lua` has a description. The settings window (Super+I -> Keybinds) shows
the same list.

| Keys | What it does |
|---|---|
| Super (tap) / Super + Space | App launcher |
| Super + Enter | Terminal |
| Super + E | File manager |
| Super + Shift + E | Yazi (files in the terminal) |
| Super + B | Browser |
| Super + Shift + Z | Editor |
| Super + I | Settings |
| Super + N | Quick settings |
| Super + C | Calendar and notifications |
| Super + V | Clipboard history |
| Super + . | Emoji |
| Super + L | Lock |
| Super + Shift + L | Lock (fallback lock screen) |
| Ctrl + Alt + Delete | Power menu |
| Super + W / Alt + F4 | Close window |
| Super + up | Maximize |
| Super + down | Minimize |
| Alt + Space / Super + Z | Window menu and snap layouts |
| Super + F | Fullscreen |
| Super + left | Snap left |
| Super + right | Snap right |
| Super + Alt + left … Super + Alt + down | Resize the tiled window |
| Super + Shift + left … Super + Shift + down | Swap with the window next to it |
| Super + Shift + Space | Float or tile |
| Alt + Tab | Switch windows |
| Alt + Shift + Tab | Switch windows, backwards |
| Super + Tab | Overview |
| Super + Ctrl + left … Super + Ctrl + down | Move focus |
| Super + Shift + S | Screenshot (region, window or screen) |
| Print | Screenshot of the screen |
| Super + 1 … Super + 0 | Go to workspace 1-10 |
| Super + Shift + 1 … Super + Shift + 0 | Move window to workspace 1-10 |
| Super + ` | Show or hide the scratchpad |
| Super + Shift + ` | Move window to the scratchpad |
| Super + mouse_down / Super + mouse_up | Next or previous workspace |
| Super + Left drag | Move window |
| Super + Right drag | Resize window |
