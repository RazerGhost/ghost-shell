# Keybinds

Generated from Hyprland's binds with `ghost keybinds`, by category; every bind in
`hypr/.config/hypr/binds.lua` has a description, "Category: what it does". The settings window
(Super+I -> Keybinds) shows the same list.

## Apps

| Keys | What it does |
|---|---|
| `Super` or `Super` + `Space` | App launcher |
| `Super` + `Enter` | Terminal |
| `Super` + `E` | File manager |
| `Super` + `Shift` + `E` | Yazi (files in the terminal) |
| `Super` + `B` | Browser |
| `Super` + `Shift` + `Z` | Editor |
| `Super` + `I` | Settings |

## Menus

| Keys | What it does |
|---|---|
| `Super` + `A` | Quick settings |
| `Super` + `N` | Notifications and calendar |
| `Super` + `Shift` + `W` | Wallpapers |
| `Super` + `Shift` + `F` | Focus mode (a timer, no pop-ups) |
| `Ctrl` + `Shift` + `Esc` | System and apps (task manager) |
| `Super` + `V` | Clipboard history |
| `Super` + `.` | Emoji |
| `Super` + `U` | Customize (desktop, dock and island, windows, quick settings) |

## Session

| Keys | What it does |
|---|---|
| `Super` + `L` | Lock |
| `Super` + `Shift` + `L` | Lock (fallback lock screen) |
| `Ctrl` + `Alt` + `Delete` or `Super` + `X` | Power menu |

## Windows

| Keys | What it does |
|---|---|
| `Super` + `W` or `Alt` + `F4` | Close window |
| `Super` + `↑` | Maximize (snapped: top quarter) |
| `Super` + `↓` | Minimize (snapped: bottom quarter) |
| `Alt` + `Space` or `Super` + `Z` | Window menu and snap layouts |
| `Super` + `F` | Fullscreen |
| `Super` + `←` | Snap left |
| `Super` + `→` | Snap right |
| `Super` + `Alt` + `←` or `Super` + `Alt` + `→` or `Super` + `Alt` + `↑` or `Super` + `Alt` + `↓` | Resize the tiled window |
| `Super` + `Shift` + `←` or `Super` + `Shift` + `→` or `Super` + `Shift` + `↑` or `Super` + `Shift` + `↓` | Swap with the window next to it |
| `Super` + `Shift` + `Space` | Float or tile |
| `Super` + `G` | Make a tab group (again: separate the windows) |
| `Super` + `Shift` + `G` | Take the window out of its tab group |
| `Alt` + ``` | Next tab |
| `Alt` + `Shift` + ``` | Previous tab |
| `Super` + `Ctrl` + `Shift` + `↓` or `Super` + `Ctrl` + `Shift` + `←` or `Super` + `Ctrl` + `Shift` + `→` or `Super` + `Ctrl` + `Shift` + `↑` | Move into the tab group next to it |
| `Super` + `Alt` + `Shift` + `←` or `Super` + `Alt` + `Shift` + `→` | Move to the screen on the left or right |
| `Alt` + `Tab` | Switch windows |
| `Alt` + `Shift` + `Tab` | Switch windows, backwards |
| `Super` + `Tab` | Overview |
| `Super` + `Ctrl` + `↑` or `Super` + `Ctrl` + `↓` | Move focus |
| `Super` + `Left drag` | Move window |
| `Super` + `Right drag` | Resize window |
| `Super` + `Shift` + `Left drag` | Take a tiled window out (or drop one into a tiled spot) |

## Workspaces

| Keys | What it does |
|---|---|
| `Super` + `Ctrl` + `←` or `Super` + `Ctrl` + `→` | Previous or next workspace |
| `Super` + `1–0` | Go to workspace 1-10 |
| `Super` + `Shift` + `1–0` | Move window to workspace 1-10 |
| `Super` + ``` | Show or hide the scratchpad (a terminal when empty) |
| `Super` + `Shift` + ``` | Move window to or from the scratchpad |
| `Super` + `Scroll down` or `Super` + `Scroll up` | Next or previous workspace |

## Capture

| Keys | What it does |
|---|---|
| `Super` + `Shift` + `S` | Screenshot (region, window or screen) |
| `Super` + `Shift` + `R` | Record the screen (again: stop) |
| `Print Screen` | Screenshot of the screen |

## Zoom

| Keys | What it does |
|---|---|
| `Super` + `+` | Zoom in (magnifier) |
| `Super` + `-` | Zoom out (magnifier) |
| `Super` + `Esc` | Zoom back to normal |
